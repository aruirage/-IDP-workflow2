02

版式 ID の読み方

版式 ID 的读法
LIAJ045 帳票シリーズ 帐票系列
-
A01 版式記号（様式） 版式记号（样式）
-
202104 版数（適用年月） 版数（适用年月）

帳票コードは別系統です。版式 ID とは対応が取れておらず、混在しています。

A01 → 040c1　／　A04 → 040c2　／　K01 → 040215(04)
桁数・書式が 2 種類あるため、帳票コードだけでは版式を特定できません。
帳票代码是另一套编号，与版式 ID 不对应，且格式不统一。

03

「まだある」と考える根拠

怀疑还有其它版式的依据
1

A01 と A04 の間に A02・A03 が無い A01 和 A04 之间跳号，缺 A02、A03

2

帳票シリーズが 2 系統ある（LIAJ045 / LIAJ001） 存在两套帐票系列

3

版式記号が 2 系統ある（A 系 / K 系） 存在两种版式记号系列（A 系 / K 系）

4

版数サフィックスが複数ある（202104 / 202604） 版数后缀不止一个，同一版式可能有改订版

04

ご確認いただきたいこと

想请贵方确认的事项
  1. 貴方に伺いたい 現在お使いの診断書は、上の 3 種以外にありますか？ 现在在用的诊断书，除了上面这 3 种还有别的吗？
  2. 貴方に伺いたい この診断書を発行しているソフトは何ですか？導入した業者と担当者はどなたですか？ 印刷这些诊断书的是什么软件？是哪家公司装的、担当是谁？
  3. 貴方に伺いたい 導入時に「帳票仕様書」を受け取っていませんか？ 导入时有没有拿到过「帳票仕様書」（版本规格书）？
  4. 帳票ベンダーへ 帳票ごとの項目一覧と、QR の分割規則の仕様書 每份帐票的字段一览，以及 QR 分割规则的规格书
