# OCR 抽出确认页：读取来源展示策略

日期：2026-08-31  
状态：已批准（方案 A）  
范围：第二期 workflow-ph2 · OCR 抽出确认执行页 UI

---

## 1. 背景与决策

### 1.1 问题

第二期 QR 读取在 OCR 抽出节点内执行，字段可能经 `QR読取` 或 `QR→OCR兜底` 写入。PRD 曾考虑在 OCR 抽出确认执行页字段卡片右上角展示读取来源标签，与 Step5 test `source-tag` 对齐。

经产品评审，读取来源对经办「对照实例改值」帮助有限；进页原因（低置信、范围越界、Master 异常等）已在待办层表达，与来源正交。

### 1.2 决策（方案 A）

**OCR 抽出确认执行页不展示读取来源。** 要確認字段仅保留 P1 高亮 + 可编辑值；不展示越界说明。

读取来源保留在：

- **Step5 综合test**（配置者验收 QR 映射）
- **引擎运行时字段元数据**（`readSource`：QR読取 / QR→OCR兜底 / OCR）
- **案件详情 / 审计日志**（争议排查，非经办卡片 UI）

### 1.3 非目标

- 不在确认页展示 `QR→OCR兜底` 等兜底提示
- 不新增 QR 专用待办类型或 QR要確認 标签
- 不改变 Step5 `fixed-doc-test-source-tag` 行为

---

## 2. UI 规格

### 2.1 OCR 抽出确认执行页

| 元素 | 展示 |
| ---- | ---- |
| 要確認字段 | P1 確認待ち 高亮 + 可编辑值 |
| 越界说明 / 配置区间 | 不展示 |
| 读取来源标签 | **不展示** |
| 办结 | 仍校验必填与正常值范围；修正后仍越界则阻断 |

### 2.2 Step5 综合test（不变）

| 元素 | 展示 |
| ---- | ---- |
| 读取来源 | 字段卡片右上角；QR 路径为 QR読取 / QR→OCR兜底；纯 OCR 不展示 |
| 范围结论 | 範囲OK / 範囲越界 + 区间（配置端） |

### 2.3 待办列表 / 任务摘要

失败原因标签（低置信、范围越界、Master 异常等）可在列表或摘要层展示；不在字段卡片重复。

---

## 3. 数据流

```
OCR 抽出节点
  ├─ 写 field.value
  └─ 写 field.readSource（QR読取 | QR→OCR兜底 | OCR）
        ├─ Step5 test UI → source-tag（QR 路径）
        ├─ 确认页 → 不消费 readSource
        └─ 案件日志 / 详情 → 争议排查
```
